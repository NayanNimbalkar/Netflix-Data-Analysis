Netflix Content Analysis — Project Description
This project analyzes the Netflix content catalogue using Python and Exploratory Data Analysis (EDA) to understand content patterns, identify factors associated with Movies vs TV Shows, analyze audience ratings and genres, and explore content trends over time.
Key Analysis
- Analyzed Movies vs TV Shows distribution.
- Studied genre composition across content types.
- Compared rating distributions between Movies and TV Shows.
- Analyzed country-wise content patterns.
- Examined Genre × Rating relationships.
- Analyzed content trends over release years.
- Created a trend-based projection for TV Show share.
- Applied the Descriptive → Diagnostic → Predictive → Prescriptive analytics framework.
Tools & Technologies
Python | Pandas | NumPy | Matplotlib | Seaborn | Plotly | Jupyter Notebook
Key Insight
The analysis found that genre composition and audience-rating profiles are associated with the differences between Movies and TV Shows, while release-year trends provide insight into how Netflix's content mix has evolved.
Project Objective
To transform Netflix catalogue data into business-oriented insights that help explain what is happening in the content library, why certain patterns exist, what could happen next, and where potential content opportunities may exist.
